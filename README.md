# StoryLoom

Home page for **StoryLoom: Temporal Knowledge Graph Guided Visual Storytelling** (Team 5, IIITDM Kancheepuram).

A single self-contained `index.html`: an animated title over a vintage comic collage. No build step and no dependencies apart from Google Fonts.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository (with `index.html` at the root).
2. In the repository go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
3. The site appears at `https://<username>.github.io/<repo>/` after a minute or two.
